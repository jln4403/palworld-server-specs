# 幻兽帕鲁服务器配置：按在线人数挑内存和带宽，4人小队到16人联机怎么配才不闪退

帕鲁私服翻车的方式其实很固定：第一天开得挺顺，玩到第三周，基地建大了、箱子塞满了、服务器里堆着两百来只帕鲁，某次加载地图直接闪退，重启之后回档十分钟。

这种事十有八九不是 CPU 不够，是内存不够。

所以这篇文章不绕弯子，把「幻兽帕鲁服务器配置」拆成几个你必须自己拍板的数字：内存给多少、几核、带宽留多大、硬盘怎么算，最后落到具体该买哪一档。所有价格和参数都来自能查到的公开信息，页面报价怎么变，以购买页为准。

## 官方配置要求只是及格线，不是推荐配置

帕鲁官方服务器文档（docs.palworldgame.com）列的运行要求大致是这样：

- CPU：4 核及以上（推荐）
- 内存：16GB，想稳定运行建议 32GB 以上；8GB 也能启动，但内存不足导致服务端崩溃的概率明显更高
- 网络：需要放行 UDP 8211 端口（默认可改）
- 存储：推荐高速 SSD，低速存储有损坏存档的风险
- 系统：Windows 64 位 / Linux 64 位

关键在「8GB 也能启动」这句话。能启动和能玩是两回事，官方自己都把 16GB 写成推荐值，说明 8GB 属于「进得去、但别指望它扛得住」的档位。

还有个比配置单更重要的事：帕鲁服务端的内存占用会随着游玩时间一路上涨。刚开机时占用很低，玩得越久、捕获的帕鲁越多、地图区块和据点加载得越全，内存曲线就一路往上走。这是游戏服务端本身的问题，不是服务器供应商的锅，所以选配置时必须留余量，而不是卡着官方最低值买。

## 决定你开多大服的那个数字：内存

不同厂商的实测口径略有差别，但方向是一致的——内存需求随在线人数和据点规模阶梯式上升。

| 同时在线人数 | 实测内存占用 | 建议配置 |
| --- | --- | --- |
| 2～4 人 | 约 5～6GB | 4 核 8G |
| 5～8 人 | 约 8～10GB | 4 核 16G |
| 9～16 人 | 约 12～14GB | 8 核 16G |
| 17 人以上 | 16GB 以上 | 16 核 32G 起 |

这些数字来自公开的第三方实测记录，会随据点建造规模、世界存档大小浮动，别当成精确值。但它们能帮你避开最典型的误判：四个人玩不代表 4G 内存够，八个人玩也不代表 8G 够，因为内存还要装下整个世界的状态，不是只装玩家。

顺带说一句，阿里云那边的说法是 4 核 16G 能撑 10～20 人，前提是限制客户端画质和渲染距离。所以同一份配置在不同口径下能带的人数会差一截，保守一点挑不会错。

## CPU 和带宽：核数不用堆，但这两项别省

**CPU。** 帕鲁服务端对多核的利用率不高，4 核基本够用，真正让服务器在怪物潮、大规模袭击事件里卡顿的是单核性能。所以与其从 4 核加到 16 核，不如把预算放在更高主频的机型上。这条和开 Minecraft 服的思路正好反过来，别照搬。

**带宽。** 每个在线玩家大约占用 0.5～1Mbps 上行带宽。4 个人的小队 5M 上行能跑，8 人以上建议 10M 起步，16 人规模就得 15M～20M。注意看的是**上行**带宽，很多云服务商首页宣传的百兆千兆是下行，跟玩家连接质量关系不大。

**硬盘。** 服务端文件加上世界存档，40G 起步比较舒服。存档会随着游玩时间持续变大，据点建得越多增长越快，低速盘不仅加载慢，严重时还会损坏存档。定期备份 `Pal/Saved/SaveGames` 目录，这是唯一能救回存档的手段。

**端口。** 帕鲁联机走 UDP 8211，只放行 TCP 会得到「能 ping 通但进不去服务器」的经典症状。如果用的是 NAT 机型（和别人共用公网 IP），需要把 8211 做端口映射出去，记住映射后的公网端口，进游戏时要用「地址:端口」的格式填。

## 三套可以直接抄的配置

不用自己从零推，按人数对号入座就行：

1. **4 人以内**：4 核 8G / 10M 上行 / 40G SSD。日常探索建家够用，但世界玩到后期建议配置自动重启。
2. **4～8 人**：4 核 16G / 15M 上行 / 40G+ SSD。这是官方推荐值对应的档位，也是绝大多数私服的实际甜点区。
3. **8 人以上或长期开服**：8 核 16G 起 / 20M 上行 / SSD 数据盘单独放存档。人多、据点大、地图区块加载量上去了，内存和带宽都得跟着加。

## 服务器买好之后，这四件事必须做

1. **映射/放行 UDP 8211。** NAT 机型在控制台的端口映射里新建规则，把 8211 映射出去；独立 IP 机型则确认安全组和系统防火墙都放行了 UDP 8211。
2. **改世界配置文件。** 面板服路径是 `pal/Pal/Saved/Config/LinuxServer/PalWorldSettings.ini`，Windows VPS 则是 `WindowsServer` 目录下的同名文件。默认情况下这个文件是空的，需要先把 `DefaultPalWorldSettings.ini`（模板文件，别直接改它）里的内容复制进去再改数值。常改的几项：`ServerName`、`ServerPassword`、`AdminPassword`、`ServerPlayerMaxNum`、`ExpRate`、`DayTimeSpeedRate`。注意配置文件里所有内容必须写在一行不换行，倍率数值要保留六位小数（比如 1 改成 0.5 要写 `0.500000`），改完重启实例才生效。
3. **配置自动重启。** 服务端长时间运行后内存占用会逼近上限，最省事的做法是设置一个监控脚本，内存占用超过阈值（比如 90%）就自动重启服务端释放内存。重启后玩家会回档几秒，但总比整个服崩掉强。
4. **定期备份存档。** 世界存档在 `Pal/Saved/SaveGames` 目录下，面板里可以直接打包下载。别等到硬盘出问题才想起来这件事。

进游戏的路径很简单：游戏里点「加入多人游戏（专用服务器）」，在下方输入你的服务器地址和端口，点「联系」就能进，把地址发给朋友他们用同样方式连。

## 几个被问得最多的配置问题

**4 核 8G 到底能不能开帕鲁服？** 能，2～4 人的小队玩原版节奏基本流畅。但服务端内存会随时间累积，长时间不重启的情况下会越来越吃紧，建议配了自动重启再用这个档位。

**要不要选 Windows？** Windows Server 图形化操作方便，代价是系统本身就吃掉一两个 G 内存。Linux 省下这部分资源，但需要命令行基础。面板服的用户不用纠结这个问题，面板已经替你封装好了。

**内存和核数哪个优先？** 内存。帕鲁的卡顿和崩溃绝大多数来自内存不足，而不是算力不够。预算有限时，宁可 4 核 16G，也别选 8 核 8G。

**多久重启一次？** 没有标准答案，取决于在线人数和据点规模。人少的两三天一次也行，10 人以上、基地建得密的，每天一次更稳。

选配置这件事没有唯一正确答案，但有一条判断标准几乎不会错：先按同时在线人数定内存，再按人数定上行带宽，CPU 挑单核不弱的中档机型，剩下的钱留给年付折扣。这样配出来的帕鲁服，大概率能陪你打完整个周末而不是打完第一晚。
